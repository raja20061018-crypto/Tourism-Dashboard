# Tourism-Dashboard
Developed an interactive Tourism Dashboard in Microsoft Excel to analyze tourism data, track key performance indicators (KPIs), and visualize trends using charts, pivot tables, and slicers. This project demonstrates data cleaning, data analysis, and dashboard design skills to support data-driven decision-making.
🌍 Tourism Dashboard | Excel Project

📊 Key Highlights:

📌 Analyzed tourism data to identify key trends and insights.

📈 Created interactive charts and visualizations.

🎯 Tracked important tourism KPIs.

🔍 Used PivotTables and slicers for dynamic analysis.

💡 Presented data-driven insights for better decision-making.

🛠️ Tools Used: Microsoft Excel
